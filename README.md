# Zeus Deploy Bot

یک ربات تلگرامی که پنل Zeus (فایل `worker-src/panel.js`) را به‌صورت خودکار روی Cloudflare Workers + D1 دیپلوی می‌کند.

## مرحله ۱ — ساخت ربات تلگرام
1. در تلگرام برو سراغ [@BotFather](https://t.me/BotFather)
2. `/newbot` بزن و اسم/یوزرنیم دلخواه بده
3. توکنی که می‌ده رو نگه دار (چیزی شبیه `123456789:ABC...`)

## مرحله ۲ — دیپلوی این ربات روی Railway
گزینه A (ساده‌تر، با Railway CLI):
```bash
npm i -g @railway/cli
cd zeus-deploy-bot
railway login
railway init
railway up
```
بعد در داشبورد Railway پروژه رو باز کن → Variables → یک متغیر اضافه کن:
```
BOT_TOKEN = <توکنی که از BotFather گرفتی>
```
و سرویس رو دوباره دیپلوی کن (Redeploy).

گزینه B: این پوشه رو به یک ریپوی GitHub پوش کن و از داشبورد Railway گزینهٔ
"Deploy from GitHub repo" رو بزن، بعد همون متغیر `BOT_TOKEN` رو ست کن.

## مرحله ۳ — استفاده از ربات
1. در تلگرام به ربات خودت `/start` بزن
2. روی دکمهٔ «🔗 اتصال به Cloudflare و ساخت پنل» بزن
3. روی دکمهٔ «🔗 باز کردن صفحهٔ ساخت توکن» بزن (مستقیم می‌بردت به Cloudflare)
   - تمپلیت آمادهٔ "Edit Cloudflare Workers" رو انتخاب کن (بیشتر دسترسی‌ها از قبل توشه)
   - فقط یک ردیف اضافه کن: Account → D1 → Edit
   - "Continue to summary" و بعد "Create Token" رو بزن (این کلیک آخر همیشه دست خودته؛ به‌دلیل امنیت Cloudflare هیچ ربات یا سایتی نمی‌تونه جای تو این کلیک رو بزنه)
4. توکن رو کپی کن و توی همون چت با ربات بفرست
5. ربات خودش:
   - یک دیتابیس D1 می‌سازه
   - فایل پنل (`worker-src/panel.js`) رو آپلود می‌کنه
   - workers.dev subdomain رو فعال می‌کنه
   - لینک نهایی پنل رو برات می‌فرسته
6. لینک رو باز کن؛ در اولین ورود، رمز پنل رو خودت تنظیم می‌کنی

## نکات امنیتی
- توکن Cloudflare هر کاربر فقط در حافظهٔ موقت ربات (RAM) نگه‌داری می‌شه، نه در فایل یا دیتابیس.
- اگر ربات چند نفره استفاده می‌شه، هر کاربر پنل مجزای خودش رو می‌گیره (اسم Worker به‌صورت رندوم ساخته می‌شه).
- بعد از دیپلوی، توصیه می‌شه محدودهٔ دسترسی توکن Cloudflare رو در صورت نیاز کم‌تر کنی یا بعد از استفاده حذفش کنی (البته چون پنل خودش هم داخلی از `CF_API_TOKEN` استفاده می‌کنه، توکن باید فعال بمونه).
